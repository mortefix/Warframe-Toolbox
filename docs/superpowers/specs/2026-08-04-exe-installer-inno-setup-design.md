# .exe installer (Inno Setup) — design

Approved in discussion 2026-08-04. Supersedes **Component 1** (and its
uninstaller) of `2026-08-04-beta-installer-auto-update-design.md`: the
installer stops being a Python-generated `.bat` and becomes a single Inno
Setup `.exe`. Everything else in that design — the in-app updater
(`app/core/updater.py`), `update.bat`, and the Settings/Home/About update
surfaces — is **unchanged**. The installed copy is still a git clone, so
auto-update keeps working as before.

## Why

The `.bat` installer was generated by `tools/installer/make_installer.py`
(a Python script that injects the token into a template). Daniel wants a real
double-click `.exe` produced by a standard installer toolchain — not a script
that emits a batch file — with a proper "Add or remove programs" entry, and it
must run from any directory.

## Decisions (locked)

- **Toolchain: Inno Setup.** Compiled with `iscc` to
  `Install Warframe Toolbox.exe`. Standard, professional, code-signable later.
- **Model: bootstrapper, not frozen app.** The `.exe` installs Python if
  missing and clones the app source from GitHub; the app still runs under
  python.org `pythonw.exe`. No PyInstaller (that remains a later chapter).
- **No credentials — the repo is public.** `mortefix/Warframe-Toolbox` was made
  public on 2026-08-04, so the installer clones anonymously
  (`https://github.com/mortefix/Warframe-Toolbox.git`) with no token. This
  removes the entire token apparatus that dogged the `.bat` approach: no
  `make_installer.py` generator, no compile-time secret, no extractable token in
  the `.exe`, no revocation kill-switch to manage. The `.exe` is the same for
  everyone and safe to hand out. (No credentials were ever in the repo — the
  warframe.market JWT lives in `%LOCALAPPDATA%`, outside the tree — so going
  public leaked nothing; it only made the source visible.)
- **MinGit downloaded at runtime, not bundled.** Bundling would push the `.exe`
  to ~45MB (past Discord's 25MB free limit); runtime download keeps it a couple
  MB, same as the `.bat` did.
- **Unsigned.** The tester sees a one-time SmartScreen "More info → Run anyway".
  Code-signing is a future add-on, out of scope here.
- **Per-user, no admin.** `PrivilegesRequired=lowest`; nothing needs UAC.

## Repo access (settled)

`mortefix/Warframe-Toolbox` is **public** and anonymously clonable — verified
2026-08-04 with a credential-free `git clone https://github.com/mortefix/Warframe-Toolbox.git`
(exit 0, 145 files, `main` at `ac32ae4`). No token, no SSH key, no auth of any
kind is involved in install or update. Build is simply
`iscc tools\installer\installer.iss` — nothing to inject.

(Fine-grained tokens were tried first and all 404'd because the repo was
private and the tokens were "Public repositories" scope; going public retired
that path entirely. Any tokens minted during that attempt should be revoked.)

## Files

- **Add** `tools/installer/installer.iss` — the Inno script (below).
- **Add** `tools/installer/BUILD.md` (or a section in DEVELOPMENT.md) — one line:
  install Inno Setup, run `iscc tools\installer\installer.iss`, ship the `.exe`.
- **Remove** `tools/installer/make_installer.py` and
  `tools/installer/install-template.bat` — the retired `.bat`-generator path.
- **Keep** `app/core/updater.py`, `update.bat`, `uninstall.bat` (the last as a
  harmless manual fallback), all update surfaces — untouched.

## installer.iss — structure

Install root `{localappdata}\Programs\WarframeToolbox`; app cloned into its
`app-repo` subfolder; MinGit (if needed) into its `mingit` subfolder. Layout
and paths match the existing `install-template.bat` exactly, so the updater and
shortcuts keep resolving.

- **`[Setup]`**: `AppId` (fixed GUID), `AppName=Warframe Toolbox`,
  `PrivilegesRequired=lowest`, `DefaultDirName={localappdata}\Programs\WarframeToolbox`,
  `DisableDirPage=yes`, `OutputBaseFilename=Install Warframe Toolbox`,
  `SetupIconFile` = a copy of `app\assets\logo.ico`,
  `UninstallDisplayIcon` / `UninstallDisplayName=Warframe Toolbox`.
- **`[Files]`**: ship `logo.ico` into the install root (the shortcut icon must
  exist independent of clone timing).
- **`[Code]`** (Pascal), idempotent — mirrors the `.bat`, each step skip-if-present:
  1. **Python** — if `{localappdata}\Programs\Python\Python311\python.exe`
     absent: `DownloadTemporaryFile` python.org `python-3.11.9-amd64.exe`, run
     `/quiet InstallAllUsers=0 PrependPath=1 Include_launcher=1
     InstallLauncherAllUsers=0 Include_test=0`.
  2. **Git** — `git` on PATH if present, else download MinGit zip, extract to
     `{app}\mingit`, use `{app}\mingit\cmd\git.exe`.
  3. **App** — if `{app}\app-repo\.git` exists: `git -C app-repo pull --ff-only`;
     else `git clone --quiet "https://github.com/mortefix/Warframe-Toolbox.git" app-repo`
     (anonymous — public repo, no token).
  4. **Deps** — `python -m pip install --quiet -r app-repo\requirements.txt`.
  Every external call checked; on failure, `MsgBox` a plain-English line and
  abort (no half-broken install).
- **`[Icons]`** (native, retires the PowerShell shortcut code): Desktop +
  Start Menu "Warframe Toolbox" →
  `{localappdata}\Programs\Python\Python311\pythonw.exe`,
  parameters `"{app}\app-repo\Warframe Toolbox.pyw"`,
  `IconFilename={app}\logo.ico`, `WorkingDir={app}\app-repo`.
- **Uninstall** — Inno's native uninstaller gives the "Add or remove programs"
  entry and removes what it installed; an `[UninstallDelete]` + uninstall-step
  `[Code]` removes the runtime-created bits Inno does not track: `{app}\app-repo`,
  `{app}\mingit`, and the `WarframeToolbox` / `WarframeToolboxWatcher` **HKCU
  Run** entries (only when their command points inside `{app}`). **User data
  (`{localappdata}\WarframeToolbox`) is never touched** — no prompt, kept
  unconditionally (a stronger guarantee than the old `.bat`'s y/N prompt).
  Python 3.11 is left installed (shared per-user runtime).

## Not in scope

- No PyInstaller / frozen-app packaging (still the next chapter).
- No code signing (SmartScreen prompt accepted for a trusted tester).
- No change to the update mechanism, branch/channel model, or user-data layout.
- No private-repo / token handling — the repo is public (see Repo access).

## Verification (manual — the installer is a build artifact)

1. **Pre-flight**: `git clone https://github.com/mortefix/Warframe-Toolbox.git`
   succeeds with no credentials (done — exit 0, `main` at `ac32ae4`).
2. **Build**: `iscc tools\installer\installer.iss` produces
   `Install Warframe Toolbox.exe`.
3. **Run from an arbitrary folder** (e.g. `D:\Downloads`), no admin: Python
   installs if absent, repo clones, deps install, Desktop + Start Menu
   shortcuts appear.
4. App launches via the shortcut, logs in against existing data.
5. Push a trivial commit → next launch pulls it, Home shows the update notice,
   About reflects the new version after restart (updater path, unchanged).
6. Re-run the installer on the same machine → idempotent (pulls instead of
   clones, no duplicate shortcuts, no errors).
7. Uninstall via "Add or remove programs" → app-repo, mingit, shortcuts, and
   the HKCU Run entries gone; `{localappdata}\WarframeToolbox` user data intact.
8. Python test suite unchanged and green (updater tests unaffected).
